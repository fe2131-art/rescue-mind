## 方法論の試行錯誤
* **自分の規則に自分が止められた**：GV は登録した停止規則（閾値 ≥ 0.05）で本実験を走らせなかった。失敗扱いにせず「未検証」と明記した。
* **間違いを直した**：「負荷が原因」と書いたテストの不安定さは誤りで、背景起動で SIGINT が無視されて継承される問題だった（I-64）。論文の「Supp. Sec. ??」も検査を足して直した（I-68）。
* **空いた GPU を放置した**：GPU を空けたまま文書修正だけをした反省から、空き検知のガード（I-71）と Stop フック（I-72）を作った。
