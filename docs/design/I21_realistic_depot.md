# I-21 design: a realistic relief depot (replaces the bare arena for the final closed-loop study)

Status: design (2026-10-17 21:10). Motivation: the user and the reviewers (R3/R4, EVAL_5/6) point out that the arena is
not realistic:
* a flat empty floor, two stations, primitive props and a stylised flame;
* known straight-line waypoints, no obstacles, no clutter;
* uniform lighting.

The checks we claim to be robust may only work because the world is easy.

## What changes

1. **Environment.** The AWS RoboMaker small warehouse (MIT-0) supplies walls, roof, floor, three shelf types, clutter,
   lamps, a pallet jack and trash cans. The assets stay outside the repository in
   `~/.cache/rescuemind/assets/aws-wh` (fetch script); the world SDF is generated by `rescuemind/depot.py`. Indoor
   lighting comes from the warehouse lamps plus a dim ambient, so there are shadows, occlusion by shelves and visual
   clutter in every camera frame.
2. **Stations on shelves and pallets.** Four supply bays in different aisles, each a pallet or a low shelf with the supply
   on it and clutter around it (cardboard boxes, a bucket, other crates). The shelter is a marked area near the dock door.
3. **Routes through aisles.** Each station has a multi-waypoint route (aisle centreline). The waypoint follower already
   takes waypoint lists through the per-run configuration (I-17 `--config` / `--centers`). The LiDAR guard stops the robot
   for an obstacle on the route (a pallet jack is placed in an aisle in some worlds), and the mission reports it.
4. **Smoke that moves.** A Gazebo particle emitter (grey smoke, slow rise) is added next to the existing flame mesh.
   Smoke-only worlds have the emitter without the flame. This is closer to D-Fire's "smoke only" photos, the case where
   our check is weakest on real images.
5. **Four stations (k = 4).** Phase 2:
   * The inventory says where each supply should be. The one-time recovery search becomes a search over the remaining
     stations in the inventory order, up to k − 1 more checks.
   * Memory and advice reorder over k stations (I-15/I-19 are already written for any station set).
   * Corollary 1 and Proposition 2 already hold for k; the depot finally tests the memory benefit that the k-station
     model predicts grows with k.

## Phases
* **Phase 1 (tonight, no Gazebo needed):** fetch script, `depot.py` world generator (two stations first, reusing the
  layout machinery), smoke emitter, routes, unit tests (SDF parses, routes clear of shelves, stations visible from the
  waypoint by ray test against the shelf boxes).
* **Phase 1 smoke test (after V, before W, about 20 min):** render the four views and drive one route.
* **Phase 2:** k = 4 stations in the mission logic, audits and memory; a registered study X:
  * about 40 closed-loop runs in randomly drawn depot worlds (supply arrangement, smoke or fire, an aisle obstacle,
    lighting);
  * expected behaviour, unsafe deliveries, time with and without memory over k = 4 stations;
  * the advice-injection condition (I-19).

## What it does not fix
It is still simulation. Real smoke, real lighting noise and real shelves differ. Real-photo studies (P/P2, Q) remain the
link to reality.
