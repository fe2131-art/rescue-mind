# v2.5 優秀賞戦略・改善ループ

## 受賞の焦点
- 創造性: Jev＋Qwenによる物資の現地再確認と、正常時の続行／異常時の拒否を同じワールドで示す。
- 技術力: ROSカメラの**視線合わせ**・撮影時刻ゲート、別プロセス速度ガード、独立移動証拠、ROS bag。
- 実用性: 物資誤配置・欠品への誤許可を測り、API/センサー故障による停止と区別する。
- 表現力: 動画中に「指示→到着→カメラの向き合わせ→Jev/Qwen判定→続行/停止」を字幕で表示、対応する実行IDを残す。

## 比較実験のアブレーション
- A: キーワードの物資ラベル照合（AI必須要件を満たさない単独比較対象）。
- B: Jev単独。
- C: Qwen3.8単独。
- D: Jev＋Qwen3.8合意方式（提出候補）。
- Camera ablation: 到着即時撮影とv2.5視線合わせ後撮影を同一条件で比較。

記録する数値: 物資識別精度、誤許可、誤拒否、AI推論時間、実行中断理由、ミッション完了率。モデル差に関する主張は実画像・正解ラベルでの比較が揃ってから。3場面×2物資×5反復は30の*未知環境*ではなく同一シーンの反復である。
