## 重要な表現上の制限

本ロボットは**物資をつかんだり運んだりしない**。使用ツールが許容する自由タスクとして「要請内容に合う物資拠点を認識し、避難所へ移動する支援巡回」と表現。自動搬送、衝突保証、実災害の安全運用などを主張しない。

## 実験計画（模型・API結果は別列）

1. 水/医療物資/無しの各条件、視野外・遮蔽・混同物資・危険通路など複数場面を**人手で正解ラベル**し、それぞれ20枚程度から開始。独立シーンIDを付け、同一フレームの重複計数を禁止。
2. Jevのみ、Qwenのみ、合意方式の`False Allow`（不適切な物資なのに先へ進む）と`False Reject`（正しい物資なのに進めない）を報告。分母とWilson 95%区間を明示。
3. 同一画像についてペアで比較し、McNemar正確検定を補助的に使用。データ依存性や対象領域への一般化は断定しない。
4. Gazeboで同一ルートを少なくとも10回、成功率・到着時間・停止理由・現地画像認識時間をCSV記録。機械的停止とVLM判定を混同しない。
5. 何を「危険」とするか、ロボットが何を観測できたか、シミュレーション内の障害物配置をプロトコルに固定。
