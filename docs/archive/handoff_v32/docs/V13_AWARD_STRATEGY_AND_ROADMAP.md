## 実験設計

1. 視覚データを水・医療・その他と、通路が明瞭/閉塞/不明瞭で層化する。1画像につき人手の正解ラベル、画像SHA256、撮影日時、シミュレーションの乱数シードを残す。
2. 比較方式はキーワード/ルール、Jev、Qwen、Jev+Qwen。モデルパラメータとプロンプト、APIモデルIDも固定する。
3. 誤許可率（実際は危険/不一致なのに許可）・誤拒否率（安全だが停止）・判断時間、ミッション到達率を別々に報告する。
4. 同じ画像で比較する際にはMcNemar検定を補助的に使える。小サンプルでは効果の確証に使わず信頼区間と失敗例を併記する。
5. 実走行で人が物資を積んでいないため「物理配送完了」は主張しない。
