# 優秀賞向け戦略 v1.0 / 2026-10-16

## 審査基準別の具体的な証拠

| 課題原文の評価軸 | この作品の独自性 | 審査者に見せる証拠 | 成功判定 |
|---|---|---|---|
| 創造性 | 現地でロボットが見た物資が指示と違うと次区間を中止する | 同一ロボット・同じ出発点での成功/不一致停止2動画 | 2ケースの分岐を実際の走行映像で示す |
| 技術力 | ROS Image + Header stamp → Jev & Qwen → gate → cmd_vel + LiDAR/odom監視 | ROS topic検査・画像sha256・ログ中のモデル結果・停止検知 | 実Gazebo上の一連ログとMP4一致 |
| 実用性 | 誤認による誤配送を防ぐ一方、不要な停止が発生し得る | 安全・危険を含む人手ラベル画像でpaired評価、Wilson CI | エラー/拒否/遅延を正直に報告 |
| 表現力 | 最初の10秒で問題→AIによる判断→分岐を示す | 90〜120秒の実録動画と簡潔な3ページPDF | 発話より映像・字幕で意図が伝わる |

## 優先順位と撤退基準

- **P0（必須）**：Gazebo上で `/cmd_vel`, `/odom`, `/scan`, `/camera` が通信し、AIなしで拠点・避難所を移動。これが未達なら全モデル拡張を停止。
- **P1（課題AI必須）**：現地画像でJev必須/Qwen3.8を実推論し、正しい場合だけ次区間へ。Jev失敗時は走行許可しない。
- **P2（受賞狙い）**：間違った物資・hazard・未知・通信失敗で停止。再実行ログと動画。
- **P3（任意）**：真値ラベルを使う10〜30例の比較試験。信頼区間は過剰解釈しない。
- **10/23までに独自Gazeboでの動作が不安定なら**：Nav2公式TurtleBot3サンプルを土台にし、Jev/Qwenの現地判断による移動目標の許可に集中する。独自シーンより確実なロボット動画を優先。

## 技術的正確性を守る

物資を「配送した」と言わず、把持・荷台なしなので **物資拠点の確認と避難所への接近** と明記する。ガードは停止支援であり安全認証ではない。Gazebo実行テストと理想運動学モデルの成功を混同しない。
