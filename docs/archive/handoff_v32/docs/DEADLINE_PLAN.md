## 優秀賞に向けた差別化

- Jev（型付き判断）× Qwen3.8（広域画像理解）× Nav2（幾何経路計画）を、説明可能な**役割分担**で結びつける。
- Jev Boxの対象不在問題を解決するNoul併用と、誤許可率 vs coverageのトレードオフの実験を独自性の中心にする。
- 比較実験は必ず現実のAPI応答に基づく。単体テストに登場するモックの精度を報告しない。
- 倒壊障害物が出たときの走行継続性はNav2の技術であり、「Jevが迂回した」とは書かない。

## 次版バックログ（v0.5）

1. カメラ付きGazebo SDF/URDFを最小単位で作成、`ros_gz_bridge`でカメラとLiDARを結線。
2. ROSノードにフレームの時刻検査・モデル呼出しのタイムアウト・誤認識時cancelTaskを設け、走行中を監視。

4. 画像ラベル付き実測セットと信頼区間を含むレポート自動生成。
