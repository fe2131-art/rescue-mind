## 評価軸の具体的な達成方法

- **創造性**: 日本語の救援依頼 → 物資棚 → 現地画像をJev 1.14.0とQwen3.8-Omni-Flashが二重に認識 → 許可なら次の地点へ向かう。同じ出発状態で物資を取り違えたときは停止する。物理的な物資運搬は未実装と明記。
- **技術力**: 二重モデルによる行動のゲーティング、ROS/Gazeboブリッジ、独立速度ガード、異常値ラッチ、センサー鮮度検査、物資到着時のフレーム時刻監査。独自ワールドの走行はNav2ではなく直接駆動と明記。
- **実用性**: Jev単独、Qwen単独、二重合意の誤許可・誤拒否を**同じ新規画像**で測る。ガードによる停止はシミュレーション試験と区別し、実測には走行中の停止時間や衝突/接近事象も記録する。
- **表現力**: 120秒の実際のGazebo録画に、自然言語の指示、推論画像、Jev/Qwen結果、ROS2指令、安全ガードの状態、次区間に進む/停止する様子を時系列字幕で配置。倍速を使うなら動画内に「2倍速」を記載する。
