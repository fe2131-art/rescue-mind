# RescueMind v3.1 — 説明資料の下書き

**課題根拠**：講座の「AI×ロボティクスによる創造的タスクの実現」。加点基準は創造性、技術力、実用性、表現力。

## 課題の概要と目的
災害対応を想定し、自然言語指示に従う差動二輪ロボットが物資拠点へ接近し、その場でROSカメラを棚に向けて静止したうえで、必須のJev 1.14.0とQwen3.8-Omni-Flashを利用して物資を確認する。判定が一致して安全側の条件を満たした場合だけ、避難所Bへの接近を許可する。

## 技術的な工夫
1. ロボットが物資棚を向く→オドメトリで静止→2枚の新規カメラ画像の画質とGazebo時計を確認。
2. JevとQwenが一致した場合のみ次区間に進む。不一致やセンサー故障は停止。
3. ROSの独立速度ガードに加え、v3.1では**実行中の速度トピック発行元監視**を独立ROSノードとして新設。想定外Publisherが現れたときはエストップを要求し終了。
4. AIの拒否とシステム故障を区別し、独立ROS観測とROS bag、監視ログで証拠を検査。

## 検証と限界
ROS/Gazeboを利用できない環境で、Python自動テスト、人工Graph異常16条件、SDF静的検査、録画終了制御のモック統合を実施。**Gazebo実走行、Jev・Qwen実API、現実的な精度、提出MP4は未検証**。ROSグラフは認証システムではなく実機安全保証ではない。物資の把持・運搬やNav2動的経路再計画は実装していない。
