# Archive: v3.2 handoff materials (historical, not part of the v3.3 submission)

These files are the planning notes, drafts, and offline-only verification logs that came
with the v3.2 handoff ZIP. They were produced **before** any real ROS 2 / Gazebo / GPU run.

* Claims in these files were never executed on a real robot stack; several turned out to
  be wrong when v3.3 actually ran Gazebo (see `docs/FINDINGS.md`).
* The legacy *cloud* lane (`rescuemind/jev.py`, `rescuemind/qwen35.py`, `scripts/v31_orchestrate.py`,
  …) and the external services/versions those notes cite were **not used and not verified** in v3.3.
  The submission runs a local Qwen2.5-VL-3B only.
* Kept unchanged for transparency of the project history.
