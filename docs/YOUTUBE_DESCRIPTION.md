## 概要欄
RescueMind：現地で「目で確かめてから」届ける災害物資ロボット（Physical AI 応用1講座 最終課題）

【背景】災害現場は計画どおりにいきません。予定の場所に物資が無い、別の物資が置かれている、火災が起きている、ということが起こります。指示どおり運ぶだけのロボットは、誤った物資や危険な場所へ届けてしまいます。
【工夫】届ける前に拠点で止まり、ローカルのAIがカメラ画像で物資と火・煙を確かめます。正面で問題がなくても横からもう一度撮り直し、迷ったら止まります。前回の記憶・ほかのロボットの報告・依頼文の「確認不要」などの聞いた情報は、行き先の順番を決めるのには使いますが、確認を省く理由にはしません（数学的に証明し、プログラムでも検証）。
【名前】RescueMind＝Rescue（救援）＋Mind（考える心）。指示をうのみにせず、自分で確かめて判断する救援ロボットという意味です。

【動画で見てほしい点】「記憶」のデモ（前回見た拠点へ直行し、着いたら必ず確かめる）、「確認不要」と言われても確認するデモ（言われたまま信じず、横から見て火を見つけて止まる）、「取り違え」のデモ（違う物資なら別の拠点を探す）。

自然な言い回しの依頼をローカルLLMが解釈し、ロボットが拠点へ自律移動。その場でカメラ画像をローカルVLM（Qwen3.5-9B / V100）で確認し、依頼どおりで火も見えないときだけ避難所Bへ向かいます。ROS 2 Jazzy × Gazebo Harmonic、映像はすべて Gazebo の実レンダリング。
※ 「届ける」は、現物確認して避難所Bへ向かう（接近する）ところまで。物資の把持・荷降ろしはシミュレーションしていません。

デモは4場面：①物資の取り違え → 別の拠点を探す ②前回の記憶で近道 → 着いたら確認 ③「確認不要」と言われても → 横から見て停止 ④倉庫で：疑わしいときは、さらに視点を増やす。
