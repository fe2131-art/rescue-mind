## 概要欄
RescueMind：現地で「目で確かめてから」届ける災害物資ロボット（Physical AI 応用1講座 最終課題）

【背景】災害現場は計画どおりにいきません。予定の場所に物資が無い、別の物資が置かれている、火災が起きている、ということが起こります。指示どおり運ぶだけのロボットは、誤った物資や危険な場所へ届けてしまいます。
【工夫】届ける前に拠点で止まり、ローカルのAIがカメラ画像で物資と火・煙を確かめます。正面で問題がなくても横からもう一度撮り直し、迷ったら止まります。前回の記憶・ほかのロボットの報告・依頼文の「確認不要」などの聞いた情報は、行き先の順番を決めるのには使いますが、確認を省く理由にはしません（数学的に証明し、プログラムでも検証）。
【名前】RescueMind＝Rescue（救援）＋Mind（考える心）。指示をうのみにせず、自分で確かめて判断する救援ロボットという意味です。
【3つの数字】（すべてシミュレーション。条件は結果を見る前に固定）
①ランダムに作った60個の世界で、期待どおりの行動 60/60、誤った物資・火のある拠点からの配達 0件
②隠れた火のある16世界で、正面だけで判断すると火の拠点へ配達 11回、横から撮り直すと 1回（火の無い世界での誤停止 0/8、偶然とは考えにくい p=0.002）。火は設計上、正面から見えにくく、測っているのは「横から見る効果」
③記憶で先に向かう拠点を決めると、物資が移されたままの8出動で所要時間（中央値）114秒→79秒（全32出動 83→73秒）。確認は省かないので危険な配達は 記憶なし 1/32・記憶つき 0/32。元に戻った出動は遠回りで遅い。

【動画で見てほしい点】「記憶」のデモ（前回見た拠点へ直行し、着いたら必ず確かめる）、「確認不要」と言われても確認するデモ（言われたまま信じず、横から見て火を見つけて止まる）、「取り違え」のデモ（違う物資なら別の拠点を探す）。

自然な言い回しの依頼をローカルLLMが解釈し、ロボットが拠点へ自律移動。その場でカメラ画像をローカルVLM（Qwen3.5-9B / V100）で確認し、依頼どおりで火も見えないときだけ避難所Bへ向かいます。ROS 2 Jazzy × Gazebo Harmonic、映像はすべて Gazebo の実レンダリング。
※ 「届ける」は、現物確認して避難所Bへ向かう（接近する）ところまで。物資の把持・荷降ろしはシミュレーションしていません。

デモは4場面：①倉庫で物資の取り違え → 別の拠点を探す ②前回の記憶で最適なルート → 着いたら確認 ③「確認不要」と言われても確認 → 火を発見 ④倉庫で火災 → 探し回らずに止まる。

※ 倍速表示：走行区間は8倍速、確認動作は4倍速、AI判断の瞬間（画像取得〜判断）は等速です（速度は動画内の左上に常時表示）。

【ほかの主な結果】（すべてシミュレーション）
・現実に近い倉庫（100の場面）：疑わしいときに左右0.8 mからも撮り直すと、火のある拠点への配達 14件 → 3件
・新しい倉庫の場面での再試験：13件 → 3件
・うその情報（「確認不要」など、12の場面）：危険な配達が起きた場面は そのまま信じる方式 12・本方式 0
・実写の火災写真：現場ごとに較正すると、火・煙の検出 282/300、火のない写真の誤警報 18/100
・今後の課題：写真に近づけた画像では、火の見逃しが 14件 → 26件に増えた
・うまくいかなかった結果も公開：「前回の記憶は、ランダムな変化でも安全」という主張は、試行数が足りず統計的に示せなかった（不成立）など、成立しなかった主張は全23件
