## 概要欄
RescueMind：現地で「目で確かめてから」届ける災害物資ロボット（Physical AI 応用1講座 最終課題）

自然な言い回しの依頼をローカルLLMが解釈し、差動二輪ロボットが物資拠点へ自律移動。拠点で静止して搭載カメラの画像を最新のローカルVLM（Qwen3.5-9B / Tesla V100）で確認し、依頼どおりと高い確信で一致したときだけ、拠点の左右からも火が無いか見直して（v3.6）避難所Bへ向かいます。物資が違えば別の拠点を探して届け、どちらにも無ければ停止して報告し、火災を見たら探索せずに停止して日本語で状況を報告します。
ROS 2 Jazzy × Gazebo Harmonic。映像はすべて Gazebo の実レンダリングです。
※ 「届ける」は、物資を現物確認して避難所Bへ向かう（接近する）ところまでです。物資の把持・荷降ろし・受け渡しはシミュレーションしていません。

デモは4場面：①言い換えた指示でも配達 ②物資の取り違え → 別の拠点を探索して配達 ③欠品 → 両拠点を確認して停止 ④物資の陰に隠れた小さな火 → 正面では見えないが、横から見て検知して停止。

※ 倍速表示：走行区間は8倍速、確認動作は3倍速、AI判断の瞬間（画像取得〜判断）は等速です（速度は動画内の左上に常時表示）。
