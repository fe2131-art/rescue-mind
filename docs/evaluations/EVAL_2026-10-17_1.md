* 減点：選択肢確率スコアリングは KnowNo、能動知覚は古典で、論文自身が近縁を認めている。Proposition 1 の「証明」は連言の単調性という自明な性質で、要旨の "We prove" は誇張。
* 減点：記憶（H）が論文の題名の柱なのに、README・説明資料・動画には登場しない。評価者の目に触れる範囲では創造性が見えにくい。

**技術力（8.0）**
* 根拠：`experiments/PREREGISTRATION_*.md` が 12 本あり、登録コミットが結果コミットの祖先であることを git で確認済み（`tab_prereg.tex`）。Gazebo 真値での独立監査、中断した評価 A/B も公開、FINDINGS 21 件（車輪軸バグで /odom 監査が通ってしまう件など）。
* 根拠：評価G は対比較 48 試行、McNemar p=0.002。評価F の有意でない結果（p=0.0625）も隠さず報告している。
* 減点：評価Gは構造上、B に不利である。母集団を「正面・左・右のいずれかで火が見える世界」とし、火は物資の陰に意図して置く。正面から 0 画素の火は、正面だけの B が見られないのは自明。p=0.002 は「横に動くと見える」という幾何の確認であり、VLM の改良の証明ではない。本当に効くかは「誤停止 0/8」「+32 秒」の側にあるが、n が小さい。

## 5. 事実誤認・誇張・数値の不整合（優先順）

1. **GitHub リポジトリが PRIVATE**（`gh repo view` で確認）。課題は「public 必須」。提出までにご本人が公開に変更すること（私は変更しない）。
2. **論文の要旨に、まだ存在しない結果の主張が TBD 付きで書かれている**（H「verified memory shortened…」「naive memory made … unsafe deliveries」、R「stayed fail-closed」、J「runs on the robot」）。`main.tex` の Cross-mission memory 節にも「結果は期待どおり」前提の文がある（`% CHECK-AFTER-H` コメント付き）。結果が出る前の主張が論文に残ると、結果が逆だった場合にそのまま提出される危険がある。
3. **説明資料 2.1 節が古い**：「火災・煙の Yes/No 質問が 0.50 未満」と書くが、v3.6 は τ_h=0.05（同じ資料の 4.4 節・README と矛盾）。
4. **問題件数がばらばら**：FINDINGS は 21 件、README と論文は 14 件、説明資料 6 章は 13 件。

6. **評価E の判断遅延**：説明資料は中央値 3.53 秒、論文（`numbers.tex`）は 3.51 秒。
7. **テスト件数**：README は約 550 件、HANDOFF は 525 件前後、論文は 506 件（これは引継ぎ時点の数）、`def test_` の数は 586。どの時点の数か明記が必要。
